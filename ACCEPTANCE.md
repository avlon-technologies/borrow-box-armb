# Shared Acceptance & Evaluation
A01 Polished browsable searchable catalog, items with photos and detail.
A02 Seeded identity switching; borrower requests dates and sees persisted pending state.
A03 Owner approves, declines; borrower cancels pending; invalid transitions fail.
A04 Conflicting pending requests allowed, but conflicting approval atomically prevented, including concurrency.
A05 Self-borrowing and unauthorized owner/borrower actions rejected on backend.
A06 Owner ready → borrower pickup → borrower return → owner completion; attributable audit trail.
A07 Before/after condition evidence attributed separately, dispute preserved.
A08 Extension request requires approval and collision recheck.
A09 Overdue indicator plus return handling.
A10 Hidden listing prevents new requests, existing reservations retained.
A11 Real persistence across restart, repeatable seed/setup.
A12 Keyboard and mobile usable; elegant human product UX, accessible feedback.
A13 Automated meaningful tests with actual execution evidence.
A14 Clear documentation and no unfinished mock button or broken flow.

Blind scoring: vision fidelity 35%, functional behaviour 25%, UX & visual quality 20%, future evolution fidelity 15% (future task withheld), architecture 5%. Hold model, budget, tools except Continuum, prompts and time limits as comparable as possible. Record cost/time/intervention. No cross-arm inspection.
